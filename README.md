O Orby é uma ferramenta de organização laboral, com o objetivo de fornecer uma plataforma de gerenciamento de tarefas e necessidades organizacionais com maior facilidade, e maior agilidade para desenvolvedores, e trabalhadores que focam no desenvolvimento do ecossistema online. A partir disso, temos que o acesso da aplicação pode ser feito de maneira web, assim como de maneira móvel, tanto pelos navegadores como por meio de aplicações instaláveis dentro do PlayStore.

## Tech Stack
A escolha de tech stack foi determinada com base na facilidade em que o desenvolvimento poderia ser dado conforme as escolhas, acelerando o desenvolvimento, e facilitando a adaptabilidade do desenvolvimento de novas features, com isso, temos que as tecnologias usadas são:

- Typescript: Linguagem de desenvolvimento com tipos, facilitando a detecção e tratamento de erros durante o desenvolvimento
- Daisyui: Biblioteca de componentes baseada no Tailwindcss, padronizando os componentes utilizados
- TailwindCSS: Biblioteca de classes de estilização CSS
- Nextjs: Framework de desenvolvimento fullstack com React, de forma a trazer todo um ecossistema de desenvolvimento
- Jest: Ferramenta de suite de testes para desenvolvimento TDD
- Supabase: Backend as a Service, tendo o PostgreSQL como banco de dados
- Docker: Containeraização dos ambientes de desenvolvimento, e homologação das variáveis de infraestrutura
- Github Actions: CI/CD do desenvolvimento
